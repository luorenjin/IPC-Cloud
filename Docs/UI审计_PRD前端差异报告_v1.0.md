## 1. 差异总览（按严重度分级）

- **A 级（PRD 明确要求但未实现）**：缺失功能模块 / 强制交互约定未落地
- **B 级（PRD 要求但实现不完整）**：有入口无能力、有能力无细节
- **C 级（视觉/体验与 PRD 设计基线偏差）**：配色、布局、文案一致性

## 4. C 级差异：视觉与 PRD 设计基线不一致（重构重点）

| 设计要素 | PRD 基线 | 现状 | 动作 |

## 5. 组件库替换影响面（Element Plus → Reka-UI + Tailwind）

- 迁移面：19 个 SFC（18 页 + H265Player + default 布局）；约 608 个 el- 标签、142 处 ElMessage、11 处 ElMessageBox、1 处 ElNotification、20 处 v-loading、5 处 el-tree、~25 张 el-table。
- 零成本保留：`ScheduleGrid.vue`、`layouts/auth.vue`、3 个 composables、`server/plugins/ws-proxy.ts`、`server/routes/media/[...path].ts`、`app.vue`、COOP/COEP routeRules（**不可删**）、h265web 播放器封装与 16:9 拟合/seek 轮询/时间轴已验证行为。
- 需自建等价物：全局 `toast()`（Reka Toast 封装）、确认弹窗（Reka AlertDialog）、列可配置表格（原生 table + Tailwind）、树（Reka Tree/可组合 + 右键菜单）、v-loading 遮罩、日期选择（Reka Calendar）、滑块（Reka Slider）、步骤条、描述列表、抽屉（Reka Dialog 侧滑）、下拉菜单（Reka DropdownMenu）、分页。
- 图标：菜单图标字符串动态渲染改为显式 SVG 组件（lucide 风格内联）。
- i18n：借重构建立 `zh-CN`/`en` 文案字典（PRD §6.6 P1 能力，ACC-09 语言切换）。

## 6. 验收基线（重构完成后逐条回归）

1. 视觉：主色 #1785E6、侧栏 #101113 整条激活、来源标签四色、三色时间轴、下划线 Tab、空状态插画，与 §4 基线一致。
2. 交互：删除设备输入名称、批量结果 Tab、模板级联提示、错误卡片（码+因+议+按钮）、待确认计数徽标、顶栏全局搜索与节点健康图标。
3. 功能：任务中心抽屉、设备配置 Tab、PTZ 预置位、消息"回放此刻"、告警策略页、个人中心（/account 修复）。
4. 工程：`grep -r "el-" pages components layouts` 为 0；`npm run build` 通过；浏览器控制台无报错；播放链路（live/playback）回归通过。
