# IpcCloud 英文术语表（阶段 6 i18n 产出）

| 项目 | 内容 |
|---|---|
| 日期 | 2026-09-10 |
| 用途 | 供审校的中英术语对照。**改译文只需改 `locales/en/*.ts` 的词条值，不需要动任何页面代码** |
| 范围 | 界面文案。代码注释、开发者 console 日志、协议字面值（`idp`/`gb28181`/`onvif`/`rtsp`）一律保持中文/原样 |

## 翻译原则

1. **句子式大小写**（Sentence case），不做每词首字母大写——`Add device` 而非 `Add Device`。
2. **按钮用祈使动词**：Save / Delete / Add / Refresh，动词在中英两侧都保持一致，同一动作全流程同名。
3. **错误文案 = 原因 + 建议**，不只说"失败"。例：`Could not reach the device. Check the IP and credentials, then try again.`
4. **空状态给下一步动作**，不只说"暂无数据"。
5. **行业术语从俗**：国标沿用 `GB/T 28181`，ONVIF/RTSP/PTZ 保持英文原形，不强行意译。
6. **占位符 `{n}` / `{name}` 不可省略、不可改名**，中英两侧必须一一对应。

## 需要重点确认的几处取舍

以下是我在没有既定叫法时做的选择，**如与贵司/客户习惯不符，请直接指出**：

| 中文 | 我的译法 | 备选 | 说明 |
|---|---|---|---|
| 自有设备 | Native device | Proprietary / First-party device | 指走自研 IDP 协议接入的设备 |
| 布防 / 布防模板 | Arming / Arming template | Guard / Defence schedule | 安防惯用 arming |
| 计划模板 | Schedule template | Plan template | 与"录像计划"配套 |
| 主码流 / 子码流 | Main stream / Sub stream | Primary / Secondary stream | 行业普遍用 main/sub |
| 上屏 | Display | Push to screen | 指把通道放到画面格 |
| 待确认（国标） | Pending approval | Pending / Unconfirmed | 指设备已注册但需管理员确认 |
| 值守总览 | Overview | Watch desk | 首页标题 |
| 流中断 | Stream lost | Stream interrupted | 告警类型 |
| 存储不足 | Storage almost full | Disk full | 阈值告警，尚未写满 |
