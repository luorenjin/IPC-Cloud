## 1. 产品概述

### 1.1 背景

项目需要一个可私有化部署的 IPC 接入与管理平台：既接入自研摄像机（IDP 私有协议），也接入已采购的 TP-LINK IPC（GB28181）以及海康、萤石等第三方设备（GB28181 / ONVIF / RTSP），在浏览器内完成预览、回放、告警与运维，不依赖厂商云与客户端插件。TP-LINK 商云作为交互与功能参考（见上游分析报告）。

### 1.2 产品目标

| 目标 | 度量 |
|---|---|
| 接入高效 | 自研设备绑定 ≤10s；第三方设备添加向导 ≤3 步；批量导入 100 台一次完成 |
| 运行稳定 | 设备状态刷新 ≤30s；预览首帧 ≤1.5s（局域网）；节点故障自动重调度 |
| 管理便捷 | 一个 Web 端完成预览/回放/告警/运维；权限到通道级 |
| 协议开放 | 同一界面管理 IDP / GB28181 / ONVIF / RTSP 设备，UI 按能力自动适配 |

### 1.3 产品定位

面向**中小规模安防/商用监控运维**（单项目 ≤1000 通道）的私有化视频管理平台，B 端使用，Web 优先。

### 1.4 核心价值

1. **多协议统一**：一套设备模型、一套调度、一个播放器。
2. **消费级接入体验**：ID+验证码/扫码/预添加（自研设备）。
3. **Web 内闭环**：多画面、PTZ、回放、下载不依赖客户端。
4. **可观测**：设备与流的健康指标、统一错误码与排障建议。

## 2. 范围与里程碑

### 2.1 MVP 范围（In）

- 账户/项目/分组/角色（通道级权限）/成员/操作日志
- 设备接入：IDP 绑定（ID+验证码、批量、预添加、局域网发现）、GB28181（参数展示、待确认、白名单）、ONVIF/RTSP（发现、手动、品牌模板）、通用导入
- 设备与通道管理：列表、筛选、详情、状态、诊断、重启、删除、转移、同步
- 实时预览：h265web.js WS-FLV、1/4 分屏、清晰度切换、截图、PTZ（有能力时）
- 录像与回放：设备端录像检索与回放（IDP/GB）、平台侧录像（计划模板）、时间轴、倍速、下载（P1）
- 告警与消息：设备/平台事件、布防模板、规则向导、消息中心、WebSocket 实时提醒
- 媒体节点管理、仪表盘、系统设置

### 2.2 明确不做（Out，MVP）

9/16 分屏、语音对讲、轮巡、P2P、分享链接、OpenAPI、外部通知（邮件/Webhook）、对象存储归档、多通道同步回放、地图、固件包库、计费。

| 里程碑 | 本 PRD 覆盖模块 |

| M0 | 5.1（登录/向导）、5.7（节点）、5.9（系统） |

| M4 | 6（非功能加固） |

## 3. 用户与角色

### 3.1 角色画像

| 角色 | 典型用户 | 核心任务 | 使用频率 |
|---|---|---|---|
| 系统管理员 | 集成商/IT | 部署、节点、项目、成员、全局设置 | 低频深度 |
| 项目管理员 | 客户 IT/安防主管 | 添加设备、分组、告警规则、权限分配 | 中频 |
| 值班员 | 保安/门店店长 | 预览、回放、处理告警 | 高频 |
| 运维工程师 | 集成商现场 | 诊断、重启、升级、查看日志 | 中频 |
| 只读访客 | 业主/合作方 | 指定通道预览 | 低频 |

### 3.2 权限模型

- **RBAC**：角色 = 菜单/操作权限 + 资源范围（项目 → 分组 → 通道，可到单通道）。
- 预置角色：超级管理员（不可删）、项目管理员、值班员、只读。
- 自定义角色支持"复制自"。

## 5. 功能需求

> 每条需求含：编号、优先级（P0 MVP 必备 / P1 首个正式版 / P2 后续）、描述、业务规则、验收标准。编号沿用上游分析报告，新增以 `-N` 后缀。

### 5.1 账户、组织与权限

#### ACC-01 登录 · P0
- 用户名 + 密码；JWT 会话（access 2h / refresh 7d）；"记住我"。
- 规则：连续 5 次失败锁定 15 分钟；密码复杂度 ≥8 位含字母数字。
- 验收：锁定期间提示剩余时间；Token 过期自动跳登录并保留原路径。

#### ACC-02 首次设置向导 · P0
- 步骤：创建项目 → 添加媒体节点（地址/secret，自检）→ 完成（引导到"添加设备"）。
- 规则：可跳过；节点自检失败显示具体原因（不可达 / secret 错误 / 版本过低）。
- 验收：向导完成后仪表盘可见；再次登录不再出现。

#### ACC-03 项目管理 · P0
- 创建/重命名/停用项目；顶栏切换；项目级设置（时区、默认停流时长）。
- 验收：切换项目后所有列表与统计随之刷新，URL 含 projectId。

#### ACC-04 设备分组 · P0
- 树形 ≤4 级；增删改、拖拽排序、拖拽移动设备。
- 规则：删除含设备的分组须先转移；分组名项目内同级唯一。
- 验收：分组树在设备列表、预览、回放、告警规则中复用同一组件与数据。

#### ACC-05 角色管理 · P0
- 权限矩阵：菜单权限 × 操作权限（查看/预览/回放/控制 PTZ/配置/删除）× 资源范围（勾选分组或通道）。
- 规则：未授权通道在所有列表/播放器/API 中不可见（403）。
- 验收：以只读角色登录，设备列表仅显示授权通道；调用越权 API 返回 403。

#### ACC-06 角色复制 · P1
- 新建角色时"复制自"已有角色。

#### ACC-07 成员管理 · P0
- 添加成员（用户名、姓名、手机/邮箱、角色、初始密码）；停用/启用；重置密码。
- 规则：停用后现有 Token 立即失效；超级管理员不可删除/降权。

#### ACC-08 操作日志 · P0
- 记录：操作者、时间、对象（设备/通道/角色…）、动作、结果、IP。
- 筛选：时间、操作者、对象类型、动作；导出 CSV。
- 验收：所有写操作 100% 落日志；日志不可修改。

#### ACC-09 个人中心 · P1
- 修改密码、个人信息、界面语言（中/英）。

### 5.2 设备接入

统一入口"添加设备"弹窗，Tab：**自有设备 | 国标接入 | 自动发现 | 手动添加 | 批量导入**。顶部固定提示"请确认设备已通电并接入网络"。所有失败给出错误码与建议（接入规范 §10）。

#### ADD-01 自有设备：ID + 验证码 · P0
- 输入：所属分组、DeviceID（17 位，自动大写）、验证码（6 位）、设备名称（可选）。
- 流程：`查找设备` → 显示型号/在线状态 → `绑定`。
- 规则：设备离线 `E1002`；验证码错误 `E7002`；已被绑定 `E7001` 并提供"申请转移 / 提交解绑申请"入口；同 ID 每小时 ≤5 次尝试。
- 验收：正确输入后 ≤10s 设备出现在列表并在线；三类错误文案与规范一致。

#### ADD-02 自有设备：扫码 · P1
- 移动端（响应式页面）调用摄像头扫 `IPC1:` 二维码，自动填充。

#### ADD-03 自有设备：预添加 · P1
- 下载模板 → 上传（DeviceID、验证码可选、名称、分组、安装位置）→ 结果表。
- 规则：7 天有效；设备上线自动绑定；失败原因可查；过期可重新激活。
- 验收："预添加设备"Tab 列表显示状态（待激活/已激活/已过期/失败）。

#### ADD-04 自有设备：局域网发现 · P1
- 私有化部署且后端与设备同网时可用：`开始发现` → 结果表（DeviceID、型号、IP、绑定状态）→ 勾选 → 输入验证码 → 批量绑定。

#### ADD-05 国标接入 · P0
- 展示当前项目 SIP 参数（编号、域、IP、端口、心跳）；`复制`；设备侧配置引导（TP-LINK/海康截图与步骤）。
- 白名单：预填国标 ID + 密码 + 分组 + 名称 → 设备注册即自动入组。
- 待确认列表：未在白名单的注册设备显示国标 ID、IP、厂商/型号、首次注册时间；`确认入组`（选分组）/ `拒绝`（加入黑名单）。
- 验收：已购 TP-LINK IPC 按引导配置后 ≤2 个心跳周期出现在待确认或自动入组；确认后通道自动同步。

#### ADD-06 自动发现（ONVIF） · P1
- `开始发现`（WS-Discovery，10s）→ 结果表（IP、厂商、型号、XAddr、已添加标记）→ 勾选 → 统一或逐台凭据 → `添加所选`。
- 结果：逐行成功/失败/原因；`重试失败项`。
- 可选：IP 段扫描（起止 IP，≤/24）。

#### ADD-07 手动添加（ONVIF/RTSP） · P1
- 协议选择：ONVIF（IP、端口、用户名、密码）/ RTSP（品牌模板 + IP + 凭据，或完整 URL）。
- `测试连接`：ONVIF 拉取型号与 Profiles；RTSP 探测编码并试拉 5s。
- 验收：测试成功显示通道预览缩略图；失败显示 `E1001/E2001/E2002/E3001/E3002` 之一。

#### ADD-08 批量导入 · P0
- 通用模板（列：source、名称、分组、DeviceID/验证码 或 国标ID/密码 或 IP/端口/协议/凭据）。
- 结果报告下载；部分失败不影响成功行。

#### ADD-09 接入后自动初始化 · P0
- 成功后自动：拉取通道、探测 main/sub、抓封面、应用项目默认录像/告警策略（可在系统设置关闭）。
- 验收：添加成功 10s 内列表出现封面缩略图。

#### ADD-10 多路径合并 · P1
- 同一物理设备经多种协议上线时按 identity 合并（idp > gb28181 > onvif > rtsp），列表显示主来源与备用来源标签。

### 5.3 设备与通道管理

#### MGR-01 设备列表 · P0
- 布局：左分组树 | 顶部类型状态卡片（IPC/NVR 总数、离线数，可折叠）| 工具栏 | 表格。
- 列（可配置显隐）：名称、来源标签（自有/国标/ONVIF/RTSP）、类型、状态（在线/离线/待确认/错误）、流状态、型号、厂商、IP、MAC、分组、通道数、固件、最后在线、操作（预览/诊断/编辑/更多）。
- 工具栏：添加设备、批量（重启/删除/转移/导出）、同步、列配置、筛选、搜索、批量搜索。
- 行展开：NVR/多通道设备显示通道子列表（通道名、启用、流状态、封面）。
- 验收：1000 台分页（50/页）加载 ≤1s；状态变更 ≤30s 反映并 WS 实时更新。

#### MGR-02 筛选与搜索 · P0
- 筛选：状态、来源、类型、分组、IP 段、是否有错误。
- 搜索：名称/IP/MAC/国标 ID/DeviceID 模糊；批量搜索（多行粘贴）。

#### MGR-03 设备详情 · P0
- Tab：概览（基本信息、能力集、网络、最近事件）| 通道 | 配置（有能力时）| 诊断 | 日志。
- 概览显示 `status.metrics`（IDP）：CPU、内存、温度、TF 容量/健康、码率。

#### MGR-04 编辑设备 · P0
- 名称、分组、安装位置、备注；第三方设备可更新凭据（更新后自动重连并回显结果）。

#### MGR-05 通道管理 · P0
- 通道名、启用开关（禁用不拉流、不出现在预览树）、封面刷新、能力集查看。

#### MGR-06 设备同步 · P1
- 手动触发：IDP `hello` 重取 / GB Catalog 重查 / ONVIF Profiles 重取；结果提示新增/删除通道数。

#### MGR-07 设备诊断 · P0
- 一键诊断项：网络可达（ping）、端口、协议握手（ONVIF/RTSP/SIP/IDP 心跳）、流状态（ZLM getMediaList）、最近错误。IDP 设备额外下发 `cmd.diag`（设备侧 ping/dns/stun）。
- 输出：每项 ✓/✗ + 耗时 + 建议文案；诊断记录保留 7 天。

#### MGR-08 远程重启 · P1
- 立即/定时；IDP `cmd.reboot`、GB `TeleBoot`、ONVIF `SystemReboot`；无能力置灰。
- 记录：成功/失败列表，按 1/7/30 天筛选。

#### MGR-09 远程配置 · P1
- IDP：编码（分辨率/帧率/码率/GOP/编码格式）、图像（亮度/对比/饱和/锐度/翻转/镜像/WDR/日夜）、OSD、录像模式、告警灵敏度与区域、时间/NTP、网络、本地账号、协议开关。
- ONVIF：编码与图像子集。
- 规则：表单按能力集与 `cfg.get` 回读渲染；提交后 5s 内回读确认；被拒项高亮显示原因。

#### MGR-10 固件升级（本地包） · P1
- 上传固件包 → 选择设备（型号匹配过滤）→ 立即/定时 → 进度（WS）。
- 规则：不匹配 `E8001`；升级中禁止其他操作；显示"请勿断电"；失败回滚 `E8003` 提示。

#### MGR-11 删除与解绑 · P0
- 二次确认（输入设备名）；软删除 30 天可恢复；停止代理流、清理映射；可选保留平台录像。

#### MGR-12 设备转移 · P1
- 跨分组/跨项目；转移后权限按目标重算；IDP 下发 `cmd.transfer`。

#### MGR-13 导出设备信息 · P1
- CSV/Excel，与当前筛选一致，不含凭据。

#### MGR-14 设备健康指标 · P1
- 通道级：码率、帧率、在线率（24h）、断流次数；1 分钟粒度保留 7 天；详情页折线图。

#### MGR-15 错误码与建议 · P0
- 全局使用接入规范 §10 错误码；所有失败提示 = 错误码 + 一句原因 + 一句建议 + 可选操作按钮（重试/诊断/查看帮助）。

### 5.4 实时预览

#### LIVE-01 播放器 · P0
- h265web.js：`webcodec_hevc` 优先，探测失败自动 `wasm_hevc`；WS-FLV 地址由 `POST /channels/{id}/play` 获取。
- 显示：标题条（通道名、码率、延时估算）、加载态、错误卡片（错误码 + 重试 + 诊断）。
- 验收：局域网首帧 ≤1.5s；错误卡片在起流超时 10s 后出现。

#### LIVE-02 按需拉流 · P0
- 打开画面才起流；关闭画面或无人观看 30s 后释放（项目可配 10~300s）。
- 验收：ZLM `getMediaList` 中无残留流。

#### LIVE-03 通道树 · P0
- 左侧分组树 + 搜索 + 在线/离线圆点 + 拖拽到画面格；离线灰显不可拖。
- 双击通道在当前选中格播放。

#### LIVE-04 分屏 · P0
- 1 / 4 分屏（P1：6/9；P2：16）；全屏；记忆上次布局与通道；分屏时默认子码流。
- 验收：4 分屏子码流 CPU 占用在主流办公 PC 可接受（<60%）。

#### LIVE-05 清晰度切换 · P0
- 主/子码流切换（能力不足置灰）；切换 ≤2s。

#### LIVE-06 播放控制 · P0
- 暂停/继续、静音/音量、截图（原始分辨率 PNG）、全屏、电子放大（P1）。

#### LIVE-07 PTZ 面板 · P0（有能力时显示）
- 8 方向（按住连续、松开停止）、变倍、变焦、速度；预置位增删改调用（≤255）。
- IDP `cmd.ptz`；GB `PTZCmd`；ONVIF `ContinuousMove/Stop/SetPreset/GotoPreset`。
- 验收：按住到画面开始移动 ≤500ms；松开 ≤300ms 停止。

#### LIVE-08 对焦控制 · P1
- 自动/近/远（IDP `cmd.focus`、ONVIF Imaging）。

#### LIVE-09 播放统计 · P1
- 当前在线播放路数、每通道观看数（节点页与仪表盘）。

### 5.5 录像与回放

#### REC-01 录像来源模型 · P0
- 通道回放"存储位置"下拉：**设备存储**（能力 `record.device.*`）/ **平台存储**（`record.platform`）；无能力项不显示。

#### REC-02 回放时间轴 · P0
- 日期选择（有录像日期高亮）；24h 横向时间轴；录像段色块（定时/事件/手动三色）；类型复选过滤；拖动定位；滚轮缩放（24h→1h→10min）；当前时间标签。
- 验收：拖动后 ≤2s 出画；时间轴与播放器时间同步误差 ≤1s。

#### REC-03 回放控制 · P0
- 暂停/继续、倍速（1/16~16 共 9 档，无能力时隐藏不支持档）、快进 30s、静音、截图、电子放大（P1）。
- 设备端回放：控制经 `record.ctrl`（IDP）/ `INFO`（GB）；平台录像：播放器本地控制。

#### REC-04 设备端录像检索 · P0
- IDP `record.query` / GB `RecordInfo`；分页聚合；结果缓存 5 分钟。

#### REC-05 平台录像计划模板 · P1
- 固定模板：全天候、工作日、周末；自定义 ≤7 个。
- 编辑器：周 × 24h 网格拖选；类型（定时/事件）；精确到分钟；复制到其他日；清空。
- 提示："修改后将同步更新使用该模板的 N 个通道"。

#### REC-06 平台录像设置 · P1
- 向导：选通道 → 选模板 → 选码流（main/sub）→ 确定。
- 列表：启用开关、修改计划、修改码流、删除；ZLM `startRecord`/`stopRecord`，`on_record_mp4` 入索引。
- 规则：事件录像需告警规则触发，前 N 秒后 M 秒（默认 5/30）。

#### REC-07 录像保留与存储概览 · P1
- 保留天数/容量阈值；≥90% 触发告警并按最旧清理；存储概览（容量、已用、预计可存天数）。

#### REC-08 录像下载 · P1
- 时间轴框选 → 任务中心 → 生成 MP4 → 下载；≥1h 片段合并。
- 设备端录像下载：IDP `record.download`（P2）。

#### REC-09 平台录像点播 · P1
- 平台录像回放走 ZLM 静态 MP4/fMP4，支持本地 seek 与倍速。

### 5.6 告警与消息

#### ALM-01 布防时间模板 · P0

#### ALM-02 告警规则向导 · P0

#### ALM-05 告警策略 · P0

#### ALM-06 消息中心 · P0

#### ALM-08 告警联动快照/录像 · P1

#### ALM-09 外部通知 · P2

#### ALM-10 首页告警概览 · P1

## 6. 非功能需求

### 6.1 性能

| 指标 | 目标 |
|---|---|
| 预览首帧（局域网，WS-FLV） | ≤1.5s |
| 端到端延时 | WS-FLV ≤1s |
| 设备状态刷新 | ≤30s |
| 告警到达 | ≤3s |
| 设备列表 1000 台分页 | ≤1s |
| 录像索引查询（单通道 30 天） | ≤200ms |
| 单节点并发（4C8G） | 200 路拉流 + 1000 路播放（以带宽为限） |
| 后端 API P95 | ≤300ms（不含媒体） |

### 6.2 可用性与可靠性

- 节点故障：通道下次点播自动重调度；无人工干预。
- 后端无状态可多实例；Redis 存会话/映射；PostgreSQL 主备（部署文档）。
- 数据保留：操作日志 ≥180 天；告警 ≥90 天；诊断记录 7 天；软删除 30 天。

### 6.3 安全

- 遵循接入规范 §11；HTTPS 强制；密码哈希 Argon2id；凭据 AES-256-GCM；日志脱敏；CSRF/CORS 配置；依赖漏洞扫描进 CI。
- 播放/推流 token 时效与绑定（§8.4 接入规范）。

### 6.4 兼容性

- 浏览器：Chrome/Edge 最新两个大版本、Safari 16+、Firefox 最新（WebCodec 不可用时 WASM 兜底）。
- 分辨率：≥1366×768；响应式到平板；扫码页适配手机。
- 多线程 WASM 需 HTTPS + COOP/COEP 响应头（部署要求）。

### 6.5 可观测性

- 后端 Prometheus 指标（设备在线数、流数、Hook 延迟、API 延迟、错误码计数）；结构化日志；ZLMediaKit_exporter 接入（可选）。

### 6.6 国际化

- 中文（默认）/英文；时间按项目时区显示。

### 6.7 部署

- Docker Compose 单机版（后端、前端、ZLM、PostgreSQL、Redis、EMQX/Mosquitto、Nginx）；K8s 清单（P1）。
- 首次启动向导（ACC-02）。
