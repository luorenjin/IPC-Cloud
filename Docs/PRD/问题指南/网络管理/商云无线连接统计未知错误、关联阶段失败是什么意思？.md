# 商云无线连接统计未知错误、关联阶段失败是什么意思？

**问题：** 商云无线连接统计未知错误、关联阶段失败是什么意思？

**答案：** 终端无线连接有四个步骤：扫描（Probe Request、Probe Response）、认证（Authentication）、关联（Association Request、Association Response）、真实身份验证（加密EAPOL） 1、认证失败：对应Authentication，可能有信号差丢包、干扰大丢包、终端协商异常等原因； 2、关联失败：对应Association的过程，可能有信号差丢包、干扰大丢包、终端协商异常等原因； 3、关联认证失败：对应真实身份验证（加密EAPOL），SSID加密才有此过程，一般是账号密码错误； 4、不在统计内出现的连接失败统称未知错误，现象不明确，具体问题具体分析
