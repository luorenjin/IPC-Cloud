## 3. 用例正文

### 3.1 注册与在线（P0）

#### TC-01 基本注册与鉴权 · P0
| 项 | 内容 |
|---|---|
| 目标 | 设备能注册到平台 SIP，Digest 鉴权通过 |
| 前置 | 平台展示 SIP ID/域/IP/端口；设备 Web 已填参数并启用 28181 |
| 步骤 | 1. 设备启用平台接入并保存<br>2. 观察设备注册状态与平台侧<br>3. 平台「待确认」或白名单自动入组 |
| 预期 | ≤2 个心跳周期出现于待确认/已入组；设备显示注册成功；错误密码时不出现 online |
| 记录 | 注册耗时、是否需确认、厂商型号字符串 |

#### TC-02 心跳与离线判定 · P0
| 项 | 内容 |
|---|---|
| 目标 | Keepalive 正常；超时按 3×周期判离线 |
| 步骤 | 1. 在线后静置 ≥2 个心跳周期 → 应保持 online<br>2. 断电或断网设备<br>3. 记录平台状态变为 offline 的时间<br>4. 恢复网络 |
| 预期 | 静置不掉线；断网后 ≤3×Keepalive（默认约 180s）offline 并产生「设备离线」告警；恢复后自动 online |
| 记录 | 实际离线判定秒数、是否推送 ALM |

#### TC-03 注册参数变体 · P1
| 项 | 内容 |
|---|---|
| 目标 | 传输模式/密码/ID 长度等常见差异 |
| 步骤 | 1. UDP 注册；2. TCP 注册（若设备支持）；3. 密码含特殊字符；4. 错误域/错误服务器 IP |
| 预期 | 支持的模式均可注册；错误配置有设备侧/平台侧可理解失败原因 |
| 记录 | 支持的传输模式 |

### 3.2 目录与通道（P0）

#### TC-04 Catalog 同步 · P0
| 项 | 内容 |
|---|---|
| 目标 | 注册后自动/手动同步通道列表 |
| 步骤 | 1. 入组后触发同步<br>2. IPC：1 通道；NVR：多通道<br>3. 设备侧增删通道后再同步 |
| 预期 | 通道名、通道国标 ID 正确；数量一致；同步结果有新增/删除提示（MGR-06 有则验，无则记「仅自动」） |
| 记录 | 通道数、名称编码（是否乱码） |

#### TC-05 通道国标编码规则 · P1
| 项 | 内容 |
|---|---|
| 目标 | 20 位编码可解析（类型/行业/序号） |
| 步骤 | 1. 导出/查看通道 ID<br>2. 对照 GB/T 28181 编码规则抽样 |
| 预期 | 长度与类型位合法；NVR 通道与 IPC 本体不冲突 |
| 记录 | 样例 ID |

### 3.3 实时点播（P0）

#### TC-06 主码流点播 · P0
| 项 | 内容 |
|---|---|
| 目标 | INVITE → 收流 → 播放器出画 |
| 步骤 | 1. 预览页选通道起播<br>2. 记录首帧时间<br>3. 连续观看 10 分钟 |
| 预期 | 首帧局域网 ≤1.5s（目标）/ ≤3s（兼容底线）；10 分钟无花屏卡死；标题条码率有值 |
| 记录 | 首帧耗时、码率、分辨率、帧率、是否 H.265 |

#### TC-07 子码流 / StreamNumber · P0
| 项 | 内容 |
|---|---|
| 目标 | 主/子切换与 SDP/StreamNumber 映射正确 |
| 步骤 | 1. 切子码流<br>2. 4 分屏场景同时拉子码流<br>3. 切回主码流 |
| 预期 | 切换 ≤2s；子码流分辨率显著更小；并发多路不互相抢流 |
| 记录 | 子码流参数、切换耗时 |

#### TC-08 TCP 被动收流 · P0
| 项 | 内容 |
|---|---|
| 目标 | 行业主流穿透方式可用 |
| 步骤 | 1. 平台优先 TCP 被动<br>2. 起播 2 路<br>3.（可选）跨 NAT 组重复 |
| 预期 | TCP 被动成功出画；若仅 UDP 成功，记 △ 并写部署要求 |
| 记录 | 支持模式：UDP / TCP 主动 / TCP 被动 |

#### TC-09 多路并发与 BYE · P0
| 项 | 内容 |
|---|---|
| 目标 | 并发起播、关闭无残留 |
| 步骤 | 1. 同设备 2 路（IPC 1 路 + 重试）或 NVR 2 通道<br>2. 关闭播放器<br>3. 检查 `getMediaList` |
| 预期 | 无观看后按策略释放；无残留 app/stream；设备侧会话结束 |
| 记录 | 残留情况、BYE 是否发出 |

### 3.4 封装与编码（P0）

#### TC-10 PS/RTP 封装 · P0
| 项 | 内容 |
|---|---|
| 目标 | ZLM 能稳定收 PS 流并输出 WS-FLV |
| 步骤 | 1. 起播并抓一段流<br>2. 确认 h265web.js WebCodec/WASM 解码路径 |
| 预期 | 无持续丢包花屏；解码核心探测日志有记录 |
| 记录 | 编码：H.264/H.265；音频：有无/G.711A 等 |

#### TC-11 主子码流编码组合 · P1
| 项 | 内容 |
|---|---|
| 目标 | 主 H.265 + 子 H.264 等组合可播 |
| 步骤 | 分别起播主/子并截图 MediaInfo |
| 预期 | 与设备 Web 配置一致；子码流适合 4 分屏 |
| 记录 | 组合表 |

### 3.5 录像检索（P0，决定回放路径）

#### TC-12 RecordInfo 按时间查询 · P0
| 项 | 内容 |
|---|---|
| 目标 | 国标录像查询可用 |
| 前置 | 设备 TF/硬盘已有 ≥2 天录像（定时 + 事件若支持） |
| 步骤 | 1. 回放页选日期<br>2. 请求时间范围检索<br>3. 跨天查询；4. 无录像日查询 |
| 预期 | 返回段落列表（起止时间）；空结果不报未知错误；分页 SN 若设备分页则聚合正确 |
| 记录 | 单次最大返回条数、耗时、类型字段是否区分定时/事件 |

#### TC-13 检索过滤（类型/通道） · P1
| 项 | 内容 |
|---|---|
| 目标 | Type 过滤、多通道隔离 |
| 步骤 | 1. 仅 Type=timing（或设备等价）<br>2. NVR 多通道交叉查询 |
| 预期 | 过滤有效或明确忽略（记 △）；通道不串数据 |
| 记录 | Type 枚举实际值 |

#### TC-14 检索性能 · P1
| 项 | 内容 |
|---|---|
| 目标 | 单通道 30 天范围可接受 |
| 步骤 | 查询 30 天，计时 3 次取中位 |
| 预期 | ≤2s 有结果或分页；目标 PRD ≤200ms 仅作自研参考 |
| 记录 | 中位耗时 |

### 3.6 录像回放（P0，R0 承诺关键）

#### TC-15 Playback 出画 · P0
| 项 | 内容 |
|---|---|
| 目标 | 设备端回放会话可建立并出画 |
| 步骤 | 1. 时间轴选段/点选时刻<br>2. 发起 Playback INVITE<br>3. 出画 |
| 预期 | ≤2s 出画（目标）/ ≤5s（兼容底线）；画面与所选时间误差 ≤10s（设备重定位特性） |
| 记录 | 出画耗时、时间偏差 |

#### TC-16 播放控制 PLAY/PAUSE · P0
| 项 | 内容 |
|---|---|
| 目标 | INFO PLAY/PAUSE 生效 |
| 步骤 | 播放中暂停 5s → 继续 → 结束会话 |
| 预期 | 暂停画面静止；继续可播；TEARDOWN 后无残留 |
| 记录 | PAUSE 后恢复是否需重 INVITE |

#### TC-17 倍速 scale · P0
| 项 | 内容 |
|---|---|
| 目标 | 设备支持的倍速档位 |
| 步骤 | 依次 0.5 / 1 / 2 / 4 / 8（设备文档有的才测） |
| 预期 | 支持档明显变速；不支持档应失败或设备忽略（记 △），UI 按能力只展示支持档 |
| 记录 | **实际支持档位列表**（写入能力 `record.device.speed`） |

#### TC-18 拖动定位 Range · P0
| 项 | 内容 |
|---|---|
| 目标 | seek/Range 重定位 |
| 步骤 | 1. 向后拖 5 分钟；2. 向前拖 1 分钟；3. 拖到录像空洞边缘 |
| 预期 | 重定位后出画 ≤2s（目标）/ ≤5s；空洞有明确处理（停/跳下一段） |
| 记录 | **定位精度**（±s）、空洞行为 |

#### TC-19 回放并发与停止 · P1
| 项 | 内容 |
|---|---|
| 目标 | 单设备并发回放上限与释放 |
| 步骤 | 1. 开 1 路回放再开第 2 路<br>2. 关闭全部 |
| 预期 | 与设备能力一致（IPC 常 ≥1）；关闭后无流残留 |
| 记录 | 并发上限 |

## 5. 与产品决策的挂钩规则

| 矩阵结果 | 产品动作 |
|---|---|
| 主流已购型号 TC-12/15 为 ✓ | R0/R1 可对「兼容国标回放」做有限承诺；写入官网/报价附件型号表 |
| 仅部分型号 ✓ | 承诺 **按型号表**；UI 按能力位灰显；交付前跑本表 |
| 大面积 ✗ | **不承诺 GB 回放**；启动平台录像最小兜底（R0-optional）或仅实时；存量项目补 NVR |
| TC-08 仅 UDP | 私有化部署文档强制「与设备同网或开放 UDP 端口段」；跨网方案改 TCP 被动优先开发 |
| TC-22 ✗ | ALM-03 对 GB 关闭；告警仅平台侧离线/流断 |
