# IpcCloud 决策记录与待定事项（Decision Log）

| 项目 | 内容 |
|---|---|
| 版本 | v1.0 |
| 日期 | 2026-09-04 |
| 用途 | 汇总当前**已定 / 讨论中 / 待定**的决策，明确优先顺序，避免硬件未定项阻塞平台与接入工作 |

---

## 1. 优先顺序

```
① 平台（云/服务端 + Web）  →  ② 设备接入（协议与流程）  →  ③ 固件通用层（L2/L3 + HAL 接口）  →  ④ 硬件与固件底层（待芯片/传感器/ISP/Flash 定后）
```

前三项现在推进；第四项**只做接口预留，不做实现决策**。

---

## 2. 决策状态

### 2.1 已定（可直接进入 PRD / 开发）

| 领域 | 决策 | 依据文档 |
|---|---|---|
| 平台技术栈 | ZLMediaKit 流媒体引擎；Go 后端；Nuxt.js 前端 | MVP 执行方案 |
| 播放器 | h265web.js（PRO 免费版）唯一播放器：直播 WS-FLV，回放 WS-FLV/MP4，后期 WebRTC | MVP 执行方案 §4 |
| 多节点 | 控制面调度（Go）+ 无状态 ZLM 节点；通道粘性；不做溯源级联 | MVP 执行方案 §5 |
| 组织与权限 | 项目 → 4 级分组 → 设备/通道；RBAC 到通道级 | 商云分析报告 §7 |
| 接入总原则 | 自研设备走私有协议 **IDP**；第三方设备走 **GB28181 首选、ONVIF/RTSP 补充**；不做云对云 | 接入方案 v1.1 §1 |
| 已购 TP-LINK IPC | GB28181 接入，纳入 MVP M1 | 接入方案 §5 |
| 海康 / 萤石 | 海康 GB28181 首选；萤石 RTSP（验证码为密码）→ ONVIF；私有 SDK 仅 P2 可选 | 接入方案 §2、§6 |
| IDP 协议 | MQTT/TLS 控制面 + RTMP(S) 按需推流；ID+验证码/扫码/预添加绑定；`record.*` 回放控制 | 接入方案 §4.2、附录 A |
| 固件功能范围 | 通用层必须提供 IDP 客户端 + ONVIF Profile S 服务端 + RTSP 服务端 + GB28181 UA + TF 录像 + OTA + 本地控制台 | 接入方案 §4.1 |
| 固件架构原则 | 平台化分层：通用层一套代码，芯片/IC 差异由 HAL 适配；能力清单（profile）数据驱动 | 固件平台化架构 |
| TF 回放路径 | IDP 设备走 `record.*`；国标设备走 RecordInfo/Playback；ONVIF/RTSP 设备走平台侧录像 | 接入方案 §8.2 |
| P2P | 不纳入 MVP；三期评估设备端 WebRTC，视硬件资源决定 | MVP 执行方案 §7 |

### 2.2 讨论中（有倾向，未冻结）

### 2.3 待定（硬件相关，暂不决策）

| 项 | 说明 | 影响范围 |
|---|---|---|
| 具体芯片型号（V100/V200/V300 或其他） | 决定内存预算、编码上限、并发 | 固件 L0、profile `limits`、SP-R1-02 规格表 |
| 图像传感器 IC | SC230AI 或其他；决定分辨率/HDR | profile `video`、调优资产 |
| 是否外接 ISP | 外接 ISP 改变 `hal_video` 的 ISP 控制路径与调优资产归属 | HAL 实现（接口不变） |
| Flash 容量与类型 | 决定 OTA 双分区可行性、协议模块是否 .so 化 | `hal_sys`、构建配置 |
| WiFi 模块型号 | BSP 驱动 + 内存 | BSP、profile `network.wifi` |
| 音频输出 | 决定"对讲"是否成立 | profile `audio.out`、IDP/ONVIF 能力 |
| SP-R1-02 规格表最终值 | 上述全部定后修订 | 核对报告 §4 建议稿 |
