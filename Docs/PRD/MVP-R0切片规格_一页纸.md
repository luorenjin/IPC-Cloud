## 1. 一页结论

| 项 | 内容 |
|---|---|
| **Goal（可量化）** | 用 **自研样机（IDP）+ 可选 1 台已购 GB 设备**，在私有化环境 30 分钟内完成：绑定上线 → 实时预览 → 设备端回放 → 告警消息 → 通道级分权；预览首帧（局域网）≤1.5s，回放拖动出画 ≤2s |
| **Why** | 产品立足点是 **自有 IPC**（消费级绑定 + 完整远程能力），不是第三方 VMS；R0 必须先证明「自己的机 + 自己的云」闭环可用、可演示、可小批量交付 |
| **Who** | 集成商/IT（系统管理员、项目管理员）；值班员（预览/告警/回放）；自研产线/联调（模拟器 + 样机） |
| **北极星** | 周活跃成功预览通道数（自研 IDP 通道占比 ≥80%） |
| **非目标（Won't in R0）** | 见 §5 |

## 2. 价值主张（自有 IPC 优先）

| 层 | 现状（What before） | R0 方案（How） | 改变后（What after） | 替代方案 |
|---|---|---|---|---|
| **自研 IPC（主）** | 板卡/固件在途，无统一云管 | IDP：ID+验证码绑定、远程配置/改密/重启、设备端 TF 回放、指标上报 | 「像消费级一样好装，像行业机一样好管」 | 厂商云（绑定生态）、本地 NVR |
| **已购 TP-LINK/海康（辅）** | 各家 APP/Web 分散管理 | GB28181 注册入同一列表，共用预览/回放/权限 | 一套 Web 管存量 + 新增自研机 | 继续用商云/萤石/iVMS |

**产品一句话（对内对外统一）**：  
> IpcCloud 是 **自有 IPC 的云端操作系统**：浏览器内完成绑定、预览、回放、告警与分权；已购国标摄像机可作为兼容设备接入，**不做**网络设备管理、大屏拼控与行业 SaaS。

## 3. 用户故事（R0 仅 5 条，INVEST）

| ID | 故事 | 验收（可测） |
|---|---|---|
| US-01 | 作为**产线/实施**，我要用 DeviceID+验证码把**自研 IPC** 绑进项目，以便出厂即上云 | ① 输入 17 位 DeviceID + 6 位验证码 → 查找 → 显示型号/在线 → 绑定；② ≤10s 出现在列表且 `online`；③ **首绑归属**：他人再绑 `E7001`；④ 错误：离线 `E1002`、验证码 `E7002`；⑤ **设备 Reset 后可重新绑定并再次归属本项目**（夺回控制权） |
| US-02 | 作为**值班员**，我要在 Web 看**自研机**实时画面，以便确认现场 | ① 通道树拖入/双击起播；② 1/4 分屏；③ 主/子码流切换 ≤2s；④ 截图 PNG；⑤ 无人看 30s（10~300 可配）停流，ZLM 无残留 |
| US-03 | 作为**值班员/业主**，我要按时间轴回放**自研机 TF 卡录像**，以便查过去 | ① 存储位置仅「设备存储」（`record.device.*`）；② 有录像日高亮 + 段色块；③ 播放/暂停/倍速（设备支持档）；④ 拖动定位出画 ≤2s；⑤ 无 TF 录像时明确空态与错误码 |
| US-04 | 作为**值班员**，我要收到设备离线/流断/移动侦测并处理，以便不漏事 | ① 离线、流断必报；② 移动侦测（IDP `event.*` 有则报）；③ WS ≤3s 进消息中心并计数；④ 详情可「回放此刻」 |
| US-05 | 作为**项目管理员**，我要给值班员只开部分通道权限，以便数据隔离 | ① 角色 = 菜单 × 操作 × 资源（到通道）；② 未授权通道列表/播放器/API 均不可见（403）；③ 写操作 100% 进操作日志 |

| ID | 故事 | 验收 |

## 4. R0 功能切片（Must）

> 编号沿用平台 PRD；**加粗 = 阻断验收**；未列出的 P0/P1 **默认不在 R0**。

### 4.1 自研 IDP 主路径（产品本体）

| 模块 | R0 条目 | 说明 |
|---|---|---|
| 账户组织 | **ACC-01 登录**、**ACC-02 首次向导**、**ACC-03 项目**、**ACC-04 分组**、**ACC-05 角色（通道级）**、**ACC-07 成员**、**ACC-08 操作日志** | 向导含「添加媒体节点自检」 |
| 设备接入 | **ADD-01 ID+验证码绑定**、**ADD-08 批量导入（IDP 列）**、**ADD-09 接入后自动初始化** | 扫码 ADD-02、预添加 ADD-03、局域网发现 ADD-04、**APP/局域网夺回工具** → **R1** |
| 设备管理 | **MGR-01 列表**、**MGR-02 筛选搜索**、**MGR-03 详情概览**、**MGR-04 编辑**、**MGR-05 通道**、**MGR-07 诊断**、**MGR-11 删除解绑**、**MGR-15 错误码建议** | 远程配置 MGR-09：**已有 38 键面板保留**，无能力键灰显即可；完整能力矩阵进 R1 |
| 运维（自有刚需） | **统一改密**（`localUser.password` 只写键）、**默认口令未改标黄**、**立即/定时重启**（IDP `cmd.reboot`） | 第三方凭据更新 → R1；MGR-10 固件升级 → **R0 最小版见下** |
| 实时预览 | **LIVE-01~06**（播放器、按需拉流、通道树、1/4 分屏、清晰度、截图等） | LIVE-07 PTZ：**样机有云台/电动镜头才启用**，无则整块隐藏 |
| 录像回放 | **REC-01 设备存储**、**REC-02 时间轴**、**REC-03 回放控制**、**REC-04 设备端检索** | 平台录像 REC-05~09 → **R1**（GB 兼容兜底见 4.2） |
| 告警 | **ALM-01 布防模板（R0 三档：全天/工作时段/关闭）**、**ALM-02 规则向导**、**ALM-03 设备事件**、**ALM-04 平台事件**、**ALM-05 策略**、**ALM-06 消息中心**、**ALM-07 WS 提醒** | 周×24h 网格编辑器、快照联动、外部通知 → R1 |
| 节点与系统 | **SYS-01 媒体节点**、**DASH-01 总览卡片**、**SET-01 全局设置**、**SET-02 IDP 服务配置（Broker/CA）** | SYS-02 详情、DASH-02/03 → R1 |
| 任务 | **任务中心最小版**（绑定批量结果、诊断中长任务） | 发现/升级长任务完善 → R1 |

### 4.2 第三方 GB 兼容路径（辅，不定义产品形态）

| 条目 | R0 要求 | 备注 |
|---|---|---|
| **ADD-05 国标接入** | SIP 参数展示/复制、白名单、待确认列表、确认入组 | 与 US-C1 对应 |
| LIVE/REC 对 GB | 实时预览可用；回放按《[TP-LINK/海康国标兼容性测试用例表](./TPLink海康_国标兼容性测试用例表.md)》结果 | **不支持设备端回放时：能力位关闭 + 文案说明**；平台录像兜底为 **R0-optional**（仅当矩阵大面积失败时启动，实现「全天定时 + ZLM startRecord」最小版，无计划模板） |

### 4.3 固件/平台最小协同（自有 IPC）

| 项 | R0 | 说明 |
|---|---|---|
| IDP 上线 | `status.hello` / Keepalive / LWT | 模拟器 + 样机各 1 路 |
| 绑定 | ID+VerifyCode，HMAC 校验；**首绑归属 + Reset 夺回** | 对齐接入规范 §5.5 |
| 直播 | 按需 RTMP(S) 推流 → ZLM → WS-FLV | LIVE-02 释放策略 |
| 回放 | `record.query` + `record.ctrl`（PLAY/PAUSE/scale/Range） | TF 分段+索引 |
| 远程 | `cfg.get/set`（与平台/模拟器三处键一致）、`cmd.reboot`、`localUser.password` | 键不同步 = 发布阻断 |
| OTA | **最小版**：上传包 → 选设备 → 进度/失败原因；无灰度、无包库 | 对应 PRD MGR-10 裁剪 |
| 能力位 | `record.device.*` / `ptz` / `reboot` / `ota` 等以 profile 声明 | UI 灰显依据 |

## 5. 明确不做（R0 Won't）

对齐战略「自有 IPC」，并防止被 TUMS/商云拖偏：

| 类别 | 不做项 |
|---|---|
| 协议 | ONVIF/RTSP 适配（萤石等）、云对云、ISUP/萤石私有 SDK、P2P |
| 视频 | 9/16 分屏、轮巡、对讲、电子放大、多通道同步回放、分享链接、H5 直播 |
| 录像 | 计划模板网格编辑器、录像下载、对象存储、平台复杂策略 |
| 告警 | 邮件/Webhook/企微、桌面通知、快照生命周期产品化 |
| 运维 | 固件包库/在线源、第三方凭据更新、备份恢复、OpenAPI |
| 平台形态 | 地图、网络拓扑、解码上墙、白标、手机 APP、计费、行业应用（连锁/幼教/家装） |
| 硬件扩展 | 其他芯片 SKU、WiFi 模组版、5MP/电动镜头变体（见[硬件基线](./硬件基线冻结与文档排查_GK7205V200_GC2053.md)；**R0 样机基线已冻结**：GK7205V200 + GC2053 + 16MB NOR + **TF 64GB 已装**） |

## 6. 验收剧本（R0 Demo / 交付门禁）

```text
[前置] docker compose 起平台；**优先 1 台真机（GK7205V200+GC2053）**，无真机时用 simulator(IDP)；可选 1 台已购 GB IPC
[真机附加] GC2053 主/子码流出画（RTSP 可拉）→ 绑定后浏览器出画
1. 向导：创建项目 + 节点自检通过
2. ADD-01 绑定自研机 → 列表 online，封面/通道可见；（夺回）Reset 后再绑成功且归属正确
3. LIVE：预览主码流，切子码流，4 分屏（若多通道/多设备），截图
4. REC：设备存储时间轴见段落 → 播放 → 倍速 → 拖动
5. 告警：触发移动侦测或模拟 event → 消息中心 ≤3s → 回放此刻
6. 权限：建「值班员」只授权 1 通道 → 二次登录越权 403
7. 运维：诊断一键跑通；改密下发成功；重启后恢复 online
8.（可选）GB 设备按兼容表测实时；回放按矩阵勾选
```

**门禁**：1–7 全绿 = R0 验收通过；8 不阻断 R0，但须附矩阵结论。

| 指标 | 目标 |
|---|---|
| 自研绑定成功率 | ≥95%（100 次模拟 + 10 次样机） |
| 预览首帧 P50（局域网） | ≤1.5s |
| 设备端回放拖动出画 | ≤2s |
| 告警到达 | ≤3s |
| 配置键下发生效 | 38 键三处一致，rejected[] = 0（标准集） |
| 未知错误码占比 | <5% |

## 7. 依赖与风险

| 类型 | 内容 | 应对 |
|---|---|---|
| 依赖 | IDP 模拟器与固件 L2 消息集与接入规范一致 | 发布前跑 simulator 闭环（接入-鉴权-心跳-起播-告警） |
