## 1. 背景与问题

### 1.1 现状问题（v1 控制台）

| 问题 | 表现 | 用户影响 |
|---|---|---|
| **功能面过窄** | 仅系统信息 / 网络 / 简单配置 / 归属 | 无法完成「装一台摄像机」的日常管理 |
| **无视频** | 无预览、无码流切换 | 无法验收画面与镜头 |
| **无事件与录像** | 无移动侦测、无录像/抓图计划 | 无法当安防机用 |
| **无图像调参** | 无亮度/宽动态/日夜/补光 | 夜间与逆光场景不可用 |
| **无下载取证** | 无按事件检索图片 | 出警/纠纷无法导出 |
| **信息架构弱** | 平铺 Tab | 对比 TP-LINK「预览/工具/设置」三区，心智成本高 |

### 1.2 对标结论（实机可见）

TP-LINK 本地 Web 已形成完整 **「看 → 查 → 管」** 闭环，我方固件控制台必须达到同级可用性，才能：

1. 产线/实施 **不开云** 就能完成安装验收；  
2. 现场排障不依赖 NVR/客户端；  
3. 为 IpcCloud 云管提供稳定设备侧能力底座。

> **定位**：设备本地管理 = 安装/调参/取证/排障；**IpcCloud** = 多设备运维与分权。两者不互相替代。

## 2. 产品目标（SMART）

| 目标 | 度量 |
|---|---|
| 功能对齐 | 覆盖实机 **预览 + 工具下载 + 设置 9 大模块**中的 P0 子集（见 §5） |
| 安装验收 | 30 分钟内完成：设密 → 预览出画 → 图像调参 → 录像计划 → 事件布防 |
| 操作路径 | 一级导航 **预览 / 工具 / 设置**；设置内二级树 ≤3 层 |
| 性能 | 预览首帧（局域网）≤1.5s；配置保存并回读 ≤2s |
| 安全 | 首次设密强制；会话超时；危险操作二次确认；口令不落日志 |

**与实机差异（产品决策）**

| 实机 | 我方 | 理由 |
|---|---|---|
| 云服务 / TP-LINK 物联 App | **云服务 / 智眸 App**（结构对齐；品牌换智眸） | 自有 App 绑定；首绑归属 + Reset 夺回 |
| 算法赋能在线商店 | **P2 本地算法开关** | 16MB Flash 无商店 |
| 物联消息推送 | **事件推送配置**（预留 URL/MQTT） | 对接自有平台 |
| 解码上墙等 | 不做 | 属云端/NVR |

## 5. 功能需求

> 优先级：**P0** = 本地验收必备；**P1** = 首个正式固件；**P2** = 后续。

### 5.1 账号与会话（P0）

| 编号 | 需求 | 验收 |
|---|---|---|
| LC-AUTH-01 | 首次访问强制设管理密码（admin） | 未设密不可进主界面 |
| LC-AUTH-02 | 登录/登出；错误提示不区分「用户不存在」 | 连续 5 次锁定 15 分钟 |
| LC-AUTH-03 | 会话超时（默认 30min）与修改密码 | 超时回登录页 |
| LC-AUTH-04 | 用户管理：改密、（P1）只读账号 | 见实机「用户管理」 |

### 5.2 预览（P0）

| 编号 | 需求 | 验收 |
|---|---|---|
| LC-PV-01 | 实时预览（浏览器，WS-FLV/HTTP-FLV 或 MJPEG 降级） | 局域网首帧 ≤1.5s |
| LC-PV-02 | **主码流 / 子码流**切换 | 切换 ≤2s；状态回显 |
| LC-PV-03 | 显示比例 4:3 / 16:9 / 100%（对齐实机） | 与实机交互一致 |
| LC-PV-04 | 单播/组播提示（本机未使能组播则灰显，对齐实机文案） | 不出现假开关 |
| LC-PV-05 | 截图 PNG、全屏、音量/静音（有音频时） | 截图原始分辨率 |

### 5.3 工具 · 图片下载（P0）

| 编号 | 需求 | 验收 |
|---|---|---|
| LC-TL-01 | 按时间范围 + **主类型**检索图片 | 类型含：定时、移动侦测、越界、区域入侵、人形、车辆、遮挡等（能力位裁剪） |
| LC-TL-02 | 结果表：文件名、抓图时间、大小、下载进度 | 分页 10/50/100/200；单次上限提示（对齐实机 10000） |
| LC-TL-03 | 单张/批量下载 | 失败行可重试 |

| 编号 | 需求 | 优先级 |
|---|---|---|
| LC-IMG-01 | 亮度、对比度、饱和度、锐度（滑杆 0–100） | P0 |
| LC-IMG-02 | 镜像/翻转（关闭/水平/垂直/水平+垂直） | P0 |
| LC-IMG-03 | 日夜配置：日夜通用 / 白天 / 夜晚 / 自动（ICR+补光联动） | P0 |
| LC-IMG-04 | 曝光模式自动/手动、曝光等级、防闪烁 50/60Hz | P0 |
| LC-IMG-05 | 补光灯：关/自动/常开；灵敏度；切换延迟 5–60s | P0 |
| LC-IMG-06 | 照明模式（红外/白光）、白光强度、**人形防过曝** | P1 |
| LC-IMG-07 | 宽动态、区域补偿、白平衡模式 | P1 |
| LC-IMG-08 | 监控场景预设（普通模式等） | P1 |
| LC-OSD-01 | 通道名、时间 OSD 开关/位置/字号 | P0 |
| LC-OSD-02 | 隐私区域覆盖（矩形遮挡，≤4） | P1 |

### 5.5 设置 · 视音频（P0）

| 编号 | 需求 | 验收 |
|---|---|---|
| LC-AV-01 | **码流策略**四选一：存储优先 / 均衡 / 画质优先 / 自定义 | 选择后自动改码率并显示「预计存储 G/天」 |
| LC-AV-02 | 主码流：编码 H.265/H.264、分辨率、帧率、码率类型（定/变）、码率上限、图像质量 1–10 | 自研机按 profile 上限；越界拦截 |
| LC-AV-03 | 子码流同上（默认 640×360） | 4 分屏/省流 |
| LC-AV-04 | 音频：开/关、编码 G.711A/U、输入增益、（有输出）对讲/监听 | 无音频硬件则整段隐藏 |

### 5.6 设置 · 事件侦测（P0）

| 编号 | 需求 | 验收 |
|---|---|---|
| LC-EV-01 | 移动侦测开关、区域、灵敏度 | 与固件 IVS 对接 |
| LC-EV-02 | 视频遮挡检测 | |
| LC-EV-03 | 智能检测（人形/机动车，**有算法才显示**） | 无算法不出现 |
| LC-EV-04 | **处理方式**多选：触发录像、抓图、消息推送、白光报警、声音报警 | 至少支持录像+抓图；推送/声光按能力 |
| LC-EV-05 | 报警声音选择与试听、播放次数（对齐实机声音列表交互） | 无音频则隐藏 |
| LC-EV-06 | 异常检测：存储满/损坏、IP 冲突、非法访问、设备离线 | 开关独立 |

### 5.7 设置 · 存储（P0）

| 编号 | 需求 | 验收 |
|---|---|---|
| LC-ST-01 | **录像计划**周×24h 网格；类型：定时 / 事件 | 与实机一致；清空计划 |
| LC-ST-02 | 录像参数：预录 5–30s、延迟 0–600s；事件类型勾选 | |
| LC-ST-03 | **抓图计划**（定时抓图 / 事件触发页签；全天网格；FTP/TUMS 开关） | 顶栏仅「定时抓图\|事件触发」 |
| LC-ST-04 | **存储管理 · 有卡分支**（`tfPresent=true`）：设备表（序号/类型/属性/剩余·总容量/状态/格式化）、容量管理（录像/抓图循环写入、录像/抓图容量配额 + 实时容量提示）、说明文案、保存 | 样机 64GB；格式化二次确认 |
| LC-ST-05 | **存储管理 · 无卡分支**（`tfPresent=false`）：空态「未检测到存储卡」；容量管理结构保留但整区禁用；保存禁用；提示先插 TF 卡 | 与有卡分支互斥，必须实现，勿只做无卡或只做有卡 |
| LC-ST-06 | **无卡联动**：`tfPresent=false` 时，**录像计划 / 抓图计划** 显示横幅「本地录像与抓图相关功能不可用」+ 空态，禁用保存与周计划；**预览**本地录像/抓图提示未插卡 | 插卡恢复后计划页与预览录像入口可用 |

**状态字段**：`S.tfPresent`（`true`=有卡 / `false`=无卡）。固件对齐时以 `hal_storage` 的 `present` 映射该字段，不得只实现单分支。

### 5.8 设置 · 网络（P0）

|---|---|---|
| GC2053/GK ISP 调参与实机手感差异 | 高 | 先实现滑杆契约，调优资产后补 |
| 16MB 装不下完整 UI | 中 | 分包 gzip；P2 页懒加载 |
| 浏览器预览编解码 | 高 | FLV/WASM 与 MJPEG 降级双路径 |
| 事件算法依赖 IVE | 中 | 能力位裁剪，无则隐藏智能页 |

## 10. 验收清单（摘要）

1. 未设密 → 强制激活；登录后顶栏为 **预览 | 工具 | 设置**。  
2. 预览可切主/子码流与 4:3/16:9/100%。  
3. 工具可按类型检索并下载图片。  
4. 设置九树可见；P0 页均可保存并刷新回读。  
5. 录像计划网格可涂改并保存。  
6. 无 WiFi/无算法时对应项隐藏或「不支持」，无假开关。  
7. **存储管理双分支**：`tfPresent=true` 显示容量表+格式化+可编辑配额；`tfPresent=false` 显示空态+禁用；录像/抓图计划在无卡时横幅禁用。固件对齐须覆盖两分支（LC-ST-04/05/06）。
8. **平台接入三分支**：IpcCloud / GB28181 / GA/T 1400 切换后表单字段互斥、注册状态文案正确；无 TUMS。
