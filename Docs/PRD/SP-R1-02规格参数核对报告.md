## 1. 结论摘要

| 判定 | 数量 | 说明 |
|---|---|---|
| 一致 | 15 | 与 GK7205V200 / SC230AI 公开规格吻合，或为纯软件项 |
| 有条件一致 | 5 | 仅在特定模式或配置下成立，需在规格中注明 |
| **不一致** | **7** | 与基线芯片或传感器物理能力矛盾，规格表必须修正 |
| 存疑 | 3 | 口径不同或依赖未列出的 BOM（WiFi 模块/音频输出/信噪比测法） |
| 需实测 | 5 | 系统级指标，只能样机验证 |

**必须修正的 7 项**

| # | 规格表原文 | 问题 | 修正 |
|---|---|---|---|
| 1 | 主芯片：瑞芯微 RV1106G2 ARM Cortex-A7 1.2GHz | 与量产基线不符；GK7205V200 为 Cortex-A7 **900MHz** | 改为 "国科微 GK7205V200，ARM Cortex-A7 900MHz" |
| 2 | 算力：0.5 TOPS | GK7205 系列**无独立 NPU** | 删除；或改为 "内置 IVE 智能加速，支持移动侦测/人形检测（无独立 NPU）" |
| 3 | DDR：内含 128MB | **GK7205V200 内置 64MB DDR2**（128MB 为 V300） | 改为 "内置 64MB DDR2" |
| 4 | 图像传感器：SC230AI 1/2.7" | SC230AI 光学尺寸为 **1/2.8"** | 改为 1/2.8" |
| 5 | 有效像素：2880×1620 | SC230AI 为 2MP（1928×1088），无法原生输出 4.6MP | 删除 |
| 6 | 主码流：2592×1944 1-30 帧/秒 | 传感器仅 2MP；**且 V200 编码上限 3MP@30（2304×1296），无论换何传感器都无法 5MP** | 删除 |
| 7 | 次码流：704×576 重复两行 | 表格错误；4:3 画幅从 16:9 源缩放会变形 | 保留一行，建议 704×396 或 640×360 |

> **V200 内存影响**：64MB 下四协议并存余量约 8MB（见《私有协议优先接入方案》§4.1.4），P2P 不可用，ONVIF Events 与 GB 回放为可裁剪项。

## 2. GK7205 三款型号能力基线（核对参照）

| 参数 | GK7205V100 | GK7205V200 | GK7205V300 |
|---|---|---|---|
| CPU | Cortex-A7 级（主频以 datasheet 为准） | Cortex-A7 900MHz | Cortex-A7 900MHz |
| 内置内存 | 64MB 级（需确认） | 64MB DDR2 级（需确认） | **128MB DDR3L（1Gb）** |
| NPU | 无 | 无 | 无（IVE 智能加速） |
| 最大编码 | 1080p 级 | 3MP@30（2304×1296） | 5MP@20 / 4MP@30 / 1080p@60（需 datasheet 确认） |
| 编码格式 | H.264/H.265 | H.264/H.265 | H.264 BP/MP/HP、H.265 MP、MJPEG |
| ISP | 2F WDR、3DNR | 2F WDR、3DNR | 2F WDR、3DNR、去雾、畸变校正 |
| Flash | SPI NOR/NAND | SPI NOR/NAND | SPI NOR/NAND |
| 网络 | 内置 FE PHY | 内置 FE PHY | 内置 FE PHY |
| 音频 | 内置 Codec | 内置 Codec | 内置 Codec |
| 外设 | SDIO、USB2.0 | SDIO、USB2.0 | SDIO、USB2.0、UART×3 |
| 海思对位 | Hi3516EV100 级 | Hi3516EV200 | Hi3516EV300（引脚兼容） |
| OpenIPC 支持 | 否 | 是（gk7205v200 族） | 是（gk7205v200 族） |

> **量产型号为 V200**：规格表 "DDR 内含 128MB" 不成立，须改为 64MB；5MP/3MP 以上分辨率不可达。以下核对以 **V200** 为目标，V300 差异括注。

## 3. 逐项核对表

### 3.1 系统

| 参数 | 规格表 | GK7205V200 基线 | 判定 | 备注 |
|---|---|---|---|---|
| 主芯片 | 瑞芯微 RV1106G2 A7 1.2GHz | 国科微 GK7205V200 A7 900MHz | **不一致** | 修正芯片型号与主频 |
| 算力 | 0.5 TOPS | 无 NPU；IVE 加速 | **不一致** | 删除或改写 |
| Flash | 128MB SPI NAND | 支持 SPI NAND 启动 | 一致（板级） | 需为 OTA A/B 预留双分区 |
| DDR | 内含 128MB | **V200 内置 64MB DDR2** | **不一致** | 改 64MB；V300 才是 128MB |

|---|---|---|---|---|

| 3D 降噪 | 支持 | ISP 3DNR | 一致 | — |
| 日夜转换 | 自动 ICR | 需 IR-CUT 硬件 + 光敏/软件判定 | 一致（板级） | 需实物确认 |

### 3.3 音视频编码

| 参数 | 规格表 | GK7205V300 基线 | 判定 | 备注 |
|---|---|---|---|---|
| 视频编码 | H.265 Main / H.264 High | H.265 MP、H.264 BP/MP/HP | 一致 | 可补 MJPEG（抓图） |
| 主码流 | 1920×1080 1-30 帧/秒 | V200 编码上限 3MP@30，1080p@30 充裕 | 一致 | — |
| 主码流 | 2592×1944 1-30 帧/秒 | 传感器 2MP；**V200 编码上限 3MP** | **不一致** | 删除 |
| 次码流 | 704×576（重复两行） | 多流编码支持 | 一致（格式错误） | 去重；建议 704×396 |

### 3.4 接口与存储

| 参数 | 规格表 | 基线 | 判定 | 备注 |
|---|---|---|---|---|
| 音频输入 | 1 MIC + 1 LINE | 内置 Codec 模拟输入 | 一致（板级） | **缺音频输出**，"对讲"不成立，需补 LINE OUT/功放或删"对讲" |
| 存储接口 | TF 卡槽 | SDIO | 一致（板级） | 注明最大容量、文件系统 |
| 网络接口 | 10/100M RJ45 | 内置 FE PHY | 一致 | — |
| 数据存储 | 视频、图片 | 软件 | 一致 | — |
| 存储机制 | 手动、定时循环 | 软件 | 一致 | **缺事件录像**（移动侦测触发），与平台时间轴"定时/事件"分类不匹配，建议补充 |

### 3.5 网络与接入协议

| 参数 | 规格表 | 判定 | 备注 |
|---|---|---|---|
| TCP/IP、UDP、RTP、RTSP、RTMP、RTCP、HTTP、DNS、DDNS、DHCP、NTP、PPPoE、SMTP、UPnP | 一致 | A7 900MHz 承载无压力；**缺 HTTPS/TLS、MQTT、WebSocket**——IDP（MQTT over TLS、RTMPS）必需，须补充 |
| WiFi 802.11b/g/n，WEP/WPA/WPA2 | 有条件一致 | **用户空间通用、内核驱动按模块**：固件 HAL 通过 Linux nl80211/wpa_supplicant 实现，对上层通用；但 GK7205 无内置 WiFi，具体模块（SDIO/USB）仍需其内核驱动与固件 blob 进入 BSP 层，且占用 2~4MB 内存（V200 需计入预算）。建议删 WEP、补 WPA3 |
| 接入协议 ONVIF、GB/T28181 | 一致 | 与固件四协议要求吻合；**缺 IDP 私有云接入协议与 RTSP 服务端**，需补充 |

## 6. 样机实测验收用例

| 用例 | 方法 | 通过标准 |
|---|---|---|
| T1 芯片识别 | 读取 chip id / `cat /proc/cpuinfo`、`free` | GK7205V200，A7 900MHz，可用内存 ≈64MB |
| T2 传感器与分辨率 | SDK 传感器探测、`v4l2-ctl`/MPP 日志 | SC230AI，最大 1920×1080@60；不存在 2592×1944 原生模式 |
| T3 主码流 1080p@30 H.265/H.264 | RTSP 拉流 24h，`ffprobe` | 帧率抖动 ≤±1fps，无花屏 |
| T4 次码流 | 验证 704×396/640×360 | 画幅无变形 |
| T5 HDR/WDR | 逆光灰阶卡 | ≥100dB 灰阶可辨，30fps |
| T6 电子快门 | 手动扫描 1/1~1/30000 | 各档曝光正确 |
| T7 最低照度 | 暗室照度计，F1.6 | 彩色 0.05Lux 可辨；黑白 0.01Lux |
| T8 ICR | 光照渐变 | 切换无抖动 |
| T9 聚焦 | 依 BOM | 与规格一致 |
| T10 音频 | MIC/LINE 录音；若有输出则对讲 | G.711A 清晰；双向 |
| T11 TF 录像 | 定时/事件/循环 72h | 索引连续，覆盖正确 |
| T12 网络协议 | 逐项 + HTTPS/MQTT-TLS/RTMPS | 全部可用 |
| T13 WiFi | 模块识别、WPA2 连接、吞吐 | ≥主码流码率×2 |
| T14 ONVIF | Device Test Tool Profile S | 核心用例通过 |
| T15 GB28181 | 注册 wvp-GB28181-pro 与我方 GB Adapter，点播/回放 | 全部成功 |
| T16 IDP | 绑定、推流、record.*、OTA A/B 回滚 | 全部成功 |
| T17 资源 | 四协议并存 + 录像 + WiFi 24h | **V200：RSS ≤56MB、CPU 均值 ≤70%**（V300：≤80MB） |
| T18 智能侦测 | IVE 移动侦测/人形检测触发事件录像 | 误报率、漏报率达产品定义阈值 |
