# 模板管理

用户可预先设置价签的展示模板.

**进入页面的方法** : **项目** **> >** **电子价签管理** **> >** **模板管理。**

模板卡片操作包括：

|   
---|---  
编辑| 可编辑当前模板信息。包括：模板名称、模板内容。  
添加| 可复制当前模板。  
删除| 可删除当前模板。  
设置为默认| 可将当前模板设置为默认模板，新增的价签绑定商品后会以默认模板的方式展示价签信息。  
  
**添加模板：**

用户点击<添加>，需要先选择基础模板样机，后续的编辑操作在基础模板的基础上完成，选择完成后点击<确定>，即可进行模板编辑。

模板可放置的元素包括：纯文本、商品属性、商品条码、纯图片、纯图形。针对不同的元素，可编辑元素的位置、长宽、字号、特殊符号、特殊效果等等。

编辑完成后点击<保存>完成模板添加。

> 注意：
> 
> 对现有模板编辑完成后，所有应用当前模板的价签都会立即更新内容。
