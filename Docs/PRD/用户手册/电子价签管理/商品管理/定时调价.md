# 定时调价

用户如果有周期性变价的需求，可提前设置定时调节功能，后续由商云负责在生效时间内控制电子价签展示显示信息。

定时调节条目介绍：

|   
---|---  
生效顺序| 代表定时调价条目的优先级，数字越小优先级越高。当一个商品在某段时间内设置了多个定时调节策略的情况下，优先级高的定时调节生效。  
定时名称| 对于该定时策略的备注信息。  
生效时间| 该定时调价的有效时间范围。  
商品数| 该定时调价涵盖的商品数目。  
是否生效| 可开启或关闭，关闭后该定时调价不再生效。  
编辑| 可编辑该定时调价信息，可编辑的信息包括：名称、重复方式、生效时间、影响的商品、生效时的商品价格。  
  
**添加定时调价：**

点击<添加>，首先设置该定时调价的名称、是否重复，若选择否，则该定时调价只生效一次，需设置具体的生效时间；若选择是，则需要设置重复方案，包含按月重复、按周重复、按日重复及每次的生效时间。

设置完成后点击<下一步>，选择需要改价的商品。点击<下一步>，设置需要修改的价格，可选中商品，点击<批量改价>，则可以一次性设置所有商品打折，点击<保存>后完成添加。
