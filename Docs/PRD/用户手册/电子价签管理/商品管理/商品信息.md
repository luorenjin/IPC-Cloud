# 商品信息

商品条目介绍：

|   
---|---  
编辑| 可编辑商品信息，除商品条目及条码的编码方式外，其他信息均可编辑。  
定时调价| 可查看当前产品的定时调价策略，并设置定时调节时要调整的价格。  
删除| 点击删除当前商品条目。  
  
#### 添加商品

用户可添加商品条目，其中商品条码、编码方式、商品名称、售价为必填项。

> 注意：
> 
> 商品条码、编码方式填写完成后不可修改，请谨慎填写。
> 
> EAN-13 码有特殊的校验方式，故存在填写完成后由于 EAN-13 格式错误导致保存失败的情况。

#### 导入/导出商品

**导入商品：**

用户需下载“商品信息模板.xls”，在模板中填写需要导入的商品信息，其中商品条码、编码方式、商品名称、售价为必填项。编写完成后，点击<导入商品>,选择刚刚编辑的商品模板，点击<导入>即可完成导入。

**导出商品：**

用户点击<导出商品>，系统将所有的商品信息以 xls 的形式下载至本地。

#### 自定义属性

使用系统过程中会遇到预置属性不可满足需求的情况，可选择自定义属性功能，自定义属性均为字符串格式。
