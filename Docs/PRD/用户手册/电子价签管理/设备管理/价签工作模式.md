# 价签工作模式

电子价签在通信时间和休眠时间功耗差异很大，故用户可依据自己店铺的更新习惯来设置电子价签的工作模式，以求获取更长的使用寿命。

#### 开启/关闭自适应

自适应：根据用户使用电子价签系统的频率，自动判断选择哪个模式。

#### 工作模式

|   
---|---  
工作模式| 模式定位及价签表现  
快速响应| 对应几乎随时都有变价需求的用户。 价签处于短周期唤醒的状态，可实时响应用户的操作。  
低功耗| 对应每天有一次变价需求的用户。 价签处于长周期唤醒的状态，响应周期约 1min。  
超低功耗| 对应长期无变价需求的用户。 价签处于超长周期唤醒的状态，响应周期为 30min。  
  
用户选择对应的模式后，点击保存后模式生效，如果价签处于低功耗或者超低功耗模式，则保存可能出现延迟。
