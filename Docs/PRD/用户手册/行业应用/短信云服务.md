# 短信云服务

TP-LINK 短信云服务为⽤户提供短信认证服务，⽆线认证设备可直接对接 TP-LINK 短信云，配置简单、使⽤便捷，网终端通过短信验证码，完成⽆线上网认证。

**进入页面：项目** **> >** **行业应用** **> >** **短信云服务** ，可查看当前项目中使用短信云认证的设备数及短信云服务认证配置 SSID 个数。

若需开启短信云服务，请**前往页面：高级** **> >** **短信云服务** 。配置方法请参考 [开通短信云服务](<um_11_1_1>)。

若需管理本项目中认证配置的 SSID，请**前往页面：项目** **> >** **网络配置** **> > SSID**，**或：高级** **> >** **短信云服务** **> >** **短信云服务认证配置** ，进行配置管理。配置方法请参考 [SSID](<um_5_1_1>) 及 [短信云服务](<um_11_1>)。

若需管理短信云服务套餐或查看数据等，请**前往页面：高级** **> >** **短信云服务，进行配置** 。配置方法请参考 [短信云服务](<um_11_1>)。
