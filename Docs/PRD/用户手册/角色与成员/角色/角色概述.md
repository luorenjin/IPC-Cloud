# 角色概述

在 TP-LINK 商用云平台中，成员的权限是通过角色划分来确定的，隶属与同一个角色的用户权限是一样的。

进入页面：成员 >> 角色，可管理角色信息。

TP-LINK 商用云平台中含系统默认角色及项目管理角色如下：

角色名| 权限备注  
---|---  
超级管理员| 拥有所有项目的所有权  
店铺管理员| 拥有该项目内价签的所有权限，包括查看与编辑价签、基站、商品、策略、模板、店员  
项目查看员| 可查看该项目内的设备、拓扑图、消息、日志、数据统计  
项目管理员| 拥有改项目内的所有权限（无费用、开通各类增值服务、项目列表管理相关权限）  
视频监控员| 可对该项目内所有监控点位进行视频预览、录像回放等操作
