# 开通直播

**进入页面：项目** **> >** **监控管理** **> >** **实时直播** **> >** **直播列表** ，点击<开通直播>。

![](../../../images/image398.png)

实时直播服务按流量收费，价格为 2.2 元/GB。

![](../../../images/image399.png)

  1. 可以选择是否要生成 H5 直播页面，点击<下一步>。



![](../../../images/image400.png)

  2. 勾选区域下的监控点，点击<下一步>。



![](../../../images/image401.png)

  3. 设置允许观看时间，点击<下一步>。



![](../../../images/image402.png)

  4. 选择或编辑 H5 页面模板，点击<开通直播>。



![](../../../images/image403.png)

  5. 开通后会生成直播地址链接，点击<确定>即可。



![](../../../images/image404.png)
