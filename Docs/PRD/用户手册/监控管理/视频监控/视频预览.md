# 视频预览

#### 预览

TP-LINK 商用云平台支持在线直接预览监控点画面，无需插件，且可以进行语音对讲等操作。

**进入页面：项目** **> >** **监控管理** **> >** **视频监控** **> >** **视频预览**

![](../../../images/image375.png)

图标| 功能  
---|---  
![](../../../images/image143.png)| 暂停播放  
![](../../../images/image144.png)| 继续播放  
![](../../../images/image145.png)| 开启实时语音对讲  
![](../../../images/image146.png)| 自动对焦  
![](../../../images/image147.png)| 聚焦前景  
![](../../../images/image148.png)| 聚焦背景  
![](../../../images/image149.png)| 当前画面清晰度为超清，点击切换画面清晰度为流畅。  
![](../../../images/image150.png)| 当前画面清晰度为流畅，点击切换画面清晰度为超清。  
  
#### 回放

TP-LINK 商用云平台支持在线回放监控点历史录像，点击<回放>进入页面。

![](../../../images/image376.png)

图标| 功能  
---|---  
![](../../../images/image143.png)| 暂停播放  
![](../../../images/image144.png)| 继续播放  
![](../../../images/image152.png)| 点击调节画面音量  
![](../../../images/image153.png)| 静音  
![](../../../images/image154.png)| 快进 30s  
![](../../../images/image155.png)| 倍速播放录像，支持 1/16、1/8、1/4、1/2、1、2、4、8、16 倍速播放。  
![](../../../images/image156.png)| 截图  
![](../../../images/image157.png)| 电子放大
